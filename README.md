## Task 2: Titanic Data Cleaning and Exploratory Data Analysis

Cleaned and explored the Titanic dataset to identify relationships between passenger characteristics, travel information, and survival outcomes.

### Objective

Prepare a real-world dataset for analysis, examine feature relationships, and communicate meaningful patterns through statistical summaries and visualizations.

### Workflow

1. Inspected columns, data types, missing values, and duplicates.
2. Prepared the dataset for analysis and handled data-quality issues.
3. Performed univariate and multivariate exploratory analysis.
4. Visualized important relationships and summarized the observed patterns.

## Running the Notebook

1. Clone or download this repository.
2. Keep the dataset file in the same directory as the notebook.
3. Open the notebook in Jupyter Notebook, JupyterLab, VS Code, or Google Colab.
4. Install any missing Python dependencies.
5. Run the cells in sequence to reproduce the analysis.

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```
